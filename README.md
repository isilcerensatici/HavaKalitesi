
# 🌫️ Air Quality Monitor via Wi-Fi

This project was developed during the **Fall 2025 semester** for the course **Wireless Network Technologies**, instructed by **Dr. Öğr. Üyesi Hasan Serdar**.
It was a collaborative project with **Muhammed Yusuf Kocaoğlan**, and we both actively contributed to the hardware and software development phases.

### 🎯 Project Goal

We designed a system using an **ESP32 microcontroller** to measure air pollution levels and present the results both on an **OLED display** and through a **web interface** for remote access.

### ⚙️ Hardware Used

* **ESP32 WROOM-32D DevKit V4** – Wi-Fi and data processing
* **MQ-135 Gas Sensor** – Air quality measurement
* **0.96" I2C OLED Display** – Real-time data output
* **Breadboard & Jumper Wires** – Prototyping
* **Micro USB Cable** – Power and data upload
* **(Optional) 3.7V Li-Po Battery** – Portability

### 💻 Software Tools

* **Arduino IDE** – Coding and uploading
* **Wokwi** – Virtual circuit simulation

### 🌐 Features

* Calculates air pollution percentage
* Real-time display via OLED
* Remote monitoring through Wi-Fi web interface

# 🌫️ Wi-Fi Hava Kalitesi Ölçer

Bu proje, **2025 güz döneminde** aldığım **Kablosuz Ağ Teknolojileri** dersi kapsamında, **Dr. Öğr. Üyesi Hasan Serdar** danışmanlığında geliştirilmiştir.
Projeyi **Muhammed Yusuf Kocaoğlan** ile birlikte yürüttük ve hem donanım hem yazılım geliştirme aşamalarında aktif görev aldık.

### 🎯 Proje Amacı

ESP32 mikrodenetleyici kullanarak ortamdaki hava kirliliği yüzdesini ölçen, sonuçları **OLED ekranda anlık olarak gösteren** ve aynı zamanda **Wi-Fi üzerinden web arayüzüyle uzaktan izlenebilir** hâle getiren bir sistem tasarladık.

### ⚙️ Kullanılan Donanımlar

* **ESP32 WROOM-32D DevKit V4** – Wi-Fi bağlantısı ve veri işleme
* **MQ-135 Gaz Sensörü** – Hava kalitesi ölçümü
* **0.96" I2C OLED Ekran** – Gerçek zamanlı veri gösterimi
* **Breadboard & Jumper Kablolar** – Prototipleme
* **Micro USB Kablo** – Güç ve veri aktarımı
* **(Opsiyonel) 3.7V Li-Po Pil** – Taşınabilirlik

### 💻 Yazılım Araçları

* **Arduino IDE** – Kod geliştirme ve yükleme
* **Wokwi** – Sanal devre simülasyonu

### 🌐 Özellikler

* Hava kirliliği yüzdesini hesaplar
* OLED ekranda anlık veri gösterimi
* Web arayüzü üzerinden uzaktan izleme imkânı
